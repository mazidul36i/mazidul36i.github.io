## 🔧 Customization Guide

### Change Primary Color
Edit the CSS variable in `public/styles/index.css`:
```css
:root {
    --main-color: #7857fe; /* Change this to your color */
}
```

### Adjust Spacing
Modify section padding:
```css
.section-padding {
    padding: 100px 0; /* Increase/decrease as needed */
}
```

### Add New Sections
1. Create HTML structure (follow existing patterns)
2. Apply section-padding class
3. Use existing CSS components
4. Test on mobile devices
